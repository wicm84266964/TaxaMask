# 物种与个体标注工作台

从主界面的“物种与个体标注”进入。它是独立工作台：适合在一张图片中标记多只个体及其物种，不需要建立部位树。同一种的三只个体保存为三个对象。原有 2D/STL 部位性状标注和 TIF 工作台继续使用各自项目。

## 一次完整操作

1. 从“文件”菜单或“更多操作”新建项目，选择空文件夹；项目入口为 `project.instance.json`。再次使用时打开这个文件。
2. 导入图片或文件夹，新增物种类别。图片复制并统一方向保存，原图不被修改。材料处理中心也可导入人工标记为可导入的图片，保留来源，但不自动确认物种。
3. 选物种后画框或多边形；每次绘制新增一个个体。也可以 SAM 点选、框选或添加背景点修正，先检查候选，再“采用候选”。修正已有对象时勾选“重描选中个体”；顶点编辑、画笔和橡皮作用于选中对象。
4. 对每只个体检查边界与物种，选择后确认；支持批量确认、改类、删除和撤销重做。确认过的对象修改后要重新确认。SAM 只帮助描边，不鉴定物种。
5. 检查图片是否还有漏标，标记整图完整；没有目标的图片须明确标记“确认无目标”。检测和分割训练不会使用未完整检查或含草稿的整图。
6. “导出”选择检测、实例分割或单体分类及相应格式；查看导出报告，再通过“训练”选本地初始权重或模型 YAML。训练完成后用“预测”选择本次模型清单，检查候选并采用、确认。

中键平移、滚轮缩放；重叠个体可重复点击切换。左侧可筛选图片检查状态，右侧可筛选个体确认状态和几何类型。多个图像属于同一标本时填写相同标本 ID，以免同一个体的不同照片跨训练与验证集合。

## 模型设置和智能体

“设置 → 通用设置”可在深空霓虹、黑金和浅色之间选择，所有工作台共用。黑金沿用 Ant Code Dashboard 的黑底、灰色面板和金色强调色；内嵌智能体直接使用 Dashboard 原生配色，不另行注入颜色覆盖，保留嵌入布局。此前选择经典深色的配置会自动使用黑金配色。

首次启动且没有已保存主题时默认黑金。更换主题后点击通用设置的“保存”，下次启动会恢复该选择；取消设置不会修改已保存主题。已有用户的浅色或深空霓虹选择不会被新默认值覆盖。

右侧“模型与任务 → 模型设置”、顶部“更多操作”和菜单“设置 → 物种与个体模型设置”打开同一配置。通用设置与其他工作台共用。SAM 权重/设备独立设置；训练和预测可选择内置 Ultralytics 或外部脚本。外部配置包括解释器、准备/训练/预测命令、支持任务、模型清单、数据格式、超时和训练参数，随当前项目保存。

外部模型须实现[实例模型契约](contracts/instance_backend_contract_zh.md)。旧部位模型按名称返回一个对象，不能直接用于同种多个体。新接口返回对象数组，核对图像、项目修订、类别及权重指纹后展示候选；采用候选不等于人工确认。

“Ask Agent”传递当前实例项目上下文。智能体可检查、校验、导出、训练、预测，以及通过队列提交草稿；不能把建议标为人工确认。操作方法见[智能体接口](contracts/instance_agent_contract_zh.md)。界面和智能体对同一项目的模型任务互斥；请求处理中发生项目修改，旧修订请求会被拒绝，需重新读取后提交。

## 文件与恢复

| 项目内位置 | 用途 |
| --- | --- |
| `project.instance.json` | 项目入口和身份 |
| `annotations.sqlite` | 类别、实例、完整 RLE 掩膜、确认、历史和模型设置 |
| `media/` | 方向统一后的图像副本 |
| `backups/` | SQLite 备份；恢复前另存当前版本，恢复标注需重新确认 |
| `imports/` | 材料导入统计及跳过原因 |
| `exports/<export_id>/` | 数据集、类别映射、来源、划分、指纹和排除报告 |
| `runs/<run_id>/` | 训练/预测配置、日志、模型清单、权重与训练账本 |
| `agent_requests/pending/`、`results/` | 智能体草稿请求及处理回执 |

编辑即时写入数据库。数据库备份不包含图片，迁移或长期备份应复制整个项目目录；保留 media，不能只复制入口 JSON。撤销删除的图像文件不会立即清理，以便恢复。

完整导出含 `COMPLETE.json`；中断目录保留 `INCOMPLETE.json`，不能进入训练。分享前检查快照和来源中的本机路径、私有备注及材料许可；当前不自动脱敏。

## 数据与验证边界

- COCO RLE 保留孔洞和断开区域。YOLO 分割只能表达单轮廓，此类复杂掩膜会阻止导出；多边形栅格化也不应被视为跨工具逐像素一致。需要完整掩膜时选择 COCO。
- 单体分类从已确认框裁剪，检测到框内包含其他已标注个体时排除。仍须人工检查裁剪内是否有未标出的其他对象。
- 默认按来源、相同图像内容和标本关联分组，约 80/10/10 划分；不强拆来源组凑比例。稀有类可能缺验证样本，训练预检会拦截空训练/验证集；分类要求所有声明类别有训练样本。
- 标注导入、训练前数据准备目前可能暂时占用界面；普通导出和模型推理使用后台任务。尚未完成万图性能及真实标本验收。
- 自动测试和三任务合成图像小训练证明技术链路可运行，不证明物种识别准确率或分类学有效性。具体证据见[实现与验证记录](validation/instance_workbench_validation_zh.md)。
