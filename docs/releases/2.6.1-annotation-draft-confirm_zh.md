# TaxaMask v2.6.1：标注草稿确认与助手启动修复

发布日期：2026-09-14

`v2.6.1` 是一次小版本。2D 工作台上的 SAM 草稿、子部位写回、撤销和列表状态改为先分清「待复核 / 已确认」，再决定能否进入本次训练。PDF 提取结果不再一律写成已完成；本机助手启动检查绕过系统代理，超时会说明真实原因。项目格式、已有确认标注和 `manual_truth` 不变。本说明处于公开发布候选阶段，不表示跨平台 CI、tag 或 GitHub Release 已经完成。

## 对研究工作流的直接变化

- 2D/STL：主工作台魔棒或框选 SAM 生成的轮廓先保存为待复核草稿。研究者看过后，可用「通过当前部位」「通过当前图」或「批量通过可训练 AI 草稿」。手工绘制完成仍立即视为人工确认。
- 2D 画布用实线/虚线和中文状态区分已确认与待复核；图片列表标题改为已确认、待复核、未标或需检查，不再用绿色代表整张图可以训练。
- 子部位专家写回主图前会说明目标图片、部位，以及会替换轮廓、新增轮廓还是只改框。专家文件缺失时自动标注按钮不可用。
- 撤销/重做会一并恢复轮廓和确认状态，不会把旁边未改动的草稿一并写成已确认。
- 启动中心：没有正式 2D 项目时，进入 2D 会先请新建或打开；取消留在启动中心。有正式项目时按钮显示「返回 2D：项目名」。
- TIF/CT：标本树和状态改成研究语言。手绘保存后的待核验状态，没有模型来源证据时不显示成「预测待核验」。预测摘要按已勾选行统计本次会替换的可编辑结果。
- PDF：提取结束会区分全部成功、部分成功、已停止、未执行和失败。「标记为可导入」只更新复核标记，不会把图片加入 2D 项目或生成训练标签。PDF 工具内询问助手会带上当前页签和文件夹。
- Agent Center：本机仪表盘健康检查不再走系统 HTTP 代理。启动等待显示已用时间，最长约 120 秒；超时后说明进程仍在、页面未就绪，并保留最近一次检查错误。启动过程中再次点击询问助手不会打断启动。

## 数据、模型与科学结论边界

- 不迁移已有 2D/STL/TIF 项目，不改写 `manual_truth`、模型权重或训练账本。
- 不批量把历史上已确认的 SAM 结果降为草稿。新生成的主工作台 SAM 轮廓按草稿保存，确认前不进入本次训练。
- 训练预检仍排除未确认部位；列表和画布现在与这一规则一致。
- 本版本改善的是确认边界、状态展示和助手启动检查，不证明分割结果的生物学准确率或分类学结论。

## 升级与产物位置

- 更新后请完整退出并重启 TaxaMask，以加载新的保存规则和启动检查。
- 无需迁移已有项目数据。
- 专家复核本科生草稿时，可在看图、改错后使用「批量通过可训练 AI 草稿」一次确认当前项目中已有轮廓的 AI 草稿；仅有框、没有轮廓的条目仍会跳过。
- 本版本不包含 API Key、本机设置、项目数据库、模型权重、PDF/TIF 数据或运行产物。
