# TaxaMask v2.4.3：TIF 自动填充与核显设备响应优化

发布日期：2026-08-08

这是 v2.4 系列的小版本维护更新，主要处理无独显或 CPU 资源紧张设备上的两个连续研究操作：在 TIF 切片上每隔数张用套索圈定部位并自动填充，以及随后打开内嵌智能体询问当前任务。更新不改变源 TIF、套索含义、标签角色、训练样本或模型推理结果。

## 研究工作流影响

- 部位自动填充预览不再因为 `QThread` 收到错误类型的 parent 而中断。这个错误与是否有 GPU 无关；独显设备也可能触发，只是线程创建路径和机器负载会影响暴露时机。
- 自动填充只计算套索实际覆盖的局部矩形，不再为每个关键切片反复扫描整张图；相邻区间复用同一关键切片的距离场。每隔约五张切片圈 ROI 的操作仍使用原有边界规则，生成掩膜保持逐像素一致。
- 连续拖动切片时只保留最后一次请求。切片、自动填充和 3D 预览线程采用低优先级，并能在任务已经不需要时取消，降低它们同时占满 CPU 的概率。
- 打开内嵌智能体前，工作台会停止仍在准备的切片和 3D 首屏。Windows 默认允许 WebEngine 自动使用可用核显完成网页合成，避免旧配置强制浏览器全部走 CPU。
- CPU 3D 投影最多使用约 25 万个采样点。该限制只影响交互预览的绘制开销，不减少保存的体素、标注、部位掩膜或训练数据。
- 内嵌 Ant-Code 同步了正式版的配置安全修复：API Key 不跨网关地址继承，网关档案可安全删除和折叠，废弃健康检查地址会清理，上下文设置不会超过模型声明上限。

## 性能复测

- `64 x 1024 x 1024` 体数据、14 个关键切片、约每 5 张一圈：自动填充由约 3.69 秒降至 1.26 秒，额外内存由约 167 MB 降至 147 MB。
- 稠密 `128^3` CPU 3D 投影：由约 0.44 秒降至 0.093 秒。
- 自动填充期间 Qt 界面心跳保持响应；取消、距离场复用、线程 parent、任务优先级和进入智能体前的任务停止均有专项测试。

这些数字来自维护机上的固定复测场景，不是对所有硬盘和处理器的速度承诺。机械硬盘读取、内存换页和旧核显驱动仍会决定实际等待时间。

## 兼容模式

Windows 默认使用 `TAXAMASK_QTWEBENGINE_RENDERING=auto`。如果某台机器出现智能体区域花屏、黑屏或 WebEngine 启动失败，可在启动前设为 `software`，也可使用智能体面板的外部浏览器入口。软件模式兼容性更高，但会重新增加 CPU 占用。

- 内嵌 Ant-Code 14 项 Node 测试、119 个 JavaScript 文件语法检查、62 个 Dashboard 资源一致性检查和发布校验通过。
