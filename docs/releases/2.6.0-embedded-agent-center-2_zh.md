# TaxaMask v2.6.0：内嵌智能体升级到 Ant Code 2.0

发布日期：2026-09-05

`v2.6.0` 是一次 Agent Center 中版本升级。TaxaMask 窗口内的智能体从 Ant Code 1.3 内嵌线切换到已适配的 2.0 TypeScript 运行时（`2.0.5-taxamask.1`）。PDF、2D/STL、TIF/CT 的项目格式、标注和训练真值边界不变。本说明处于公开发布候选阶段，不表示跨平台 CI、tag 或 GitHub Release 已经完成。

## 对研究工作流的直接变化

- 启动中心内嵌的对话界面改为 Ant Code 2.0 Dashboard。需要 Node.js 22.18 或更新版本；旧 Node 会无法启动内嵌智能体。
- 浅色工作台下，Agent 面板跟随工作台配色：聊天区、输入栏、设置里的下拉框和「允许的主机」不再残留独立版深色底。深色工作台继续使用深色嵌入。
- 内嵌启动改为专用入口，不再加载完整独立 CLI，首次打开 Agent Center 会更快。
- 代码搜索改用随包提供的 ripgrep，不再依赖系统是否安装了 `rg`。技能列表、待办和 MCP 列表会显示实际条目，而不是空的 `{}`。
- 联网搜索在免 key 前提下增加维基百科开放接口，并在维基不可达时继续尝试必应页面和 DuckDuckGo。这是额外检索渠道，不是稳定的全网搜索引擎；结果需要引用，不能当成分类学结论。
- 源码写入守卫、项目内配置、PDF 证据与文献 Skill、修复面板入口都保留。GUI 无法启动时，仍可用 `启动AntCode修复面板.bat` 打开内嵌 Dashboard。

## 数据、模型与科学结论边界

- 不迁移已有 2D/STL/TIF 项目，不改写 `manual_truth`、模型权重或训练账本。
- AI 草稿、人工真值和训练数据的边界与 v2.5.0 相同。
- 搜索或智能体回答不能代替标本复核、文献阅读或分类学判断。
- 本版本不包含 API Key、本机设置、项目数据库、模型权重、PDF/TIF 数据或运行产物。

## 升级与产物位置

- 更新后请完整退出并重启 TaxaMask，以加载新的 Node 入口和 Qt 嵌入样式。
- 无需迁移已有项目数据。首次打开 Agent Center 时，会话仍由项目内 `.lab-agent/sessions/` 管理。
- 若设置了网络允许主机列表，需要把 `en.wikipedia.org`、`zh.wikipedia.org`、`www.bing.com` 加进去，否则整次 `web_search` 可能被询问或拦住。
- Windows 系统代理由内嵌运行时读取；不必在 TaxaMask 里再填代理端口。浏览器能打开的网站，不等于 Node 直连也能打开。

## 验证、限制与待完成门禁

- 研究者已在开发仓完成浅色/深色 Agent 界面、启动、代码搜索和短对话人工验收；这不等同于 PDF、2D、TIF 全流程逐项人工测试。
- 开发仓内嵌运行时 `npm test`：1268 次测试调用，1265 通过、3 跳过、0 失败。
- 与本次改动直接相关的 Python 套件 `tests.test_gui_smoke`、`tests.test_agentic_contract`、`tests.test_agent_context_routes`、`tests.test_embedded_taxonomy_paper_finder`、`tests.test_tif_agent_context`：155 通过、0 失败。
- 已知限制：DuckDuckGo HTML 仍可能被反爬；维基百科在国内直连常超时，需系统代理；必应页面刮取没有长期保证。
- 正式发布还要求同一提交通过 Windows、Ubuntu、macOS Python 3.12、Embedded Agent Center 和 Paper Distill Skill bundle 检查。最终以正式仓 CI 和 Release 门禁为准。
