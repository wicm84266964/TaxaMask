# TaxaMask v2.6.3：材料处理中心与可登记材料接口

发布日期：2026-10-19

`v2.6.3` 是一次小版本。起始页和菜单里原来的 PDF 工具入口改名为「材料处理中心」。目前接到标注工作台的仍是 PDF 文献证据途径，文献筛选、图文提取、复核和导入都还在原处。新的材料接口可以单独登记，默认不沿用 `pdf_evidence`，也不能自动写成训练真值。项目格式、已有标注和 `manual_truth` 不变。本说明处于公开发布候选阶段，不表示跨平台 CI、tag 或 GitHub Release 已经完成。

## 对研究工作流的直接变化

- 起始页右侧卡片、两个按钮、文件菜单和进入后的标题都改为「材料处理中心」。Agent 入口改为「让 Agent 规划材料处理流程」。
- 材料处理中心里的询问按钮改为「带上当前材料处理状态询问助手」。停在「文献筛选」时带去筛选文件夹、方案和批次设置；停在「数据提取」时带去提取文件夹、数据库、多模态开关和 Poppler 状态。
- 切换这两个页签会更新助手记住的当前页，不会因此自动往对话里插一条新消息。
- 以后增加第 3、第 4 种材料接入方式时，应在 `AntSleap/ui/material_intake_registry.py` 单独登记，并给页签写上自己的 `material_page_id`。没有登记、或登记时未声明接到工作台的新页，询问助手时不会带上 PDF 文件夹和文献发现 Skill，也不会允许导入标注项目。
- 「1. 文献筛选」和「2. 数据提取」的操作步骤没有改。没有加入点击即可添加途径的按钮。

## 数据、模型与科学结论边界

- 不迁移已有 PDF、2D/STL、TIF/CT 项目，不改写标注、`manual_truth`、模型权重或训练账本。
- `open_pdf_evidence_tools`、`pdf_evidence`、`pdf_evidence_context`，以及 `taxamask-pdf-evidence` 和 `taxonomy-paper-finder` 这两个 Skill 名称不变。已有 PDF 数据库和导入工作台的路径不用迁移。
- 新材料接口在明确写出导入契约并把 `connected_to_workbench` 设为真之前，不能进入 2D/STL 或 TIF 项目，也不能变成训练真值。
- 本版本只调整入口名称和助手如何识别当前材料页，不证明文献判断、分割结果或分类学结论。

## 升级与产物位置

- 更新后请完整退出并重启 TaxaMask，才能看到新的入口名称。
- 无需迁移已有项目数据。
- 本版本不包含 API Key、本机设置、项目数据库、模型权重、PDF/TIF 数据或运行产物。
