# TaxaMask v2.4.1：安全加固与脑区输入可信度修复

发布日期：2026-08-05

这是 v2.4 系列的小版本维护更新。日常标注、候选复核和 PDF 筛选交互没有明显变化，主要改进外部模型调用、权重读取、内嵌 Agent 写入保护，以及 TIF/CT 脑区候选输入的失败保护逻辑。

## 研究工作流影响

- 外部 2D、Blink 和 TIF 后端改为直接传递参数，不再经系统 Shell 解释，降低项目路径或配置内容被当成命令执行的风险。包含 `&&`、管道或重定向的旧式复合命令需要改为单独的包装脚本。
- 项目自有 PyTorch 权重统一使用仅权重安全模式读取，避免不可信检查点在加载时执行任意 Python 对象。
- Python 图像、PDF、网络与模型文件锁依赖提高到已修复的安全版本下限，避免旧环境在重复安装时继续保留已知有漏洞的版本。
- 内嵌 Ant-Code 对后台 Shell、配置文件、Skill 和 vendor 配置的源码写入保护更完整；正常问答和研究工作流不受影响，需要改源码时仍会走明确授权。
- nnU-Net v2 在 Windows 上默认使用顺序预测导出，避免大型三维预测通过多进程管道时失败；代价是该阶段可能稍慢，但更适合长时间、大体积研究运行。
- nnU-Net 自定义 Blink trainer 可从 TaxaMask 预测入口正确解析，标准 trainer 仍交回 nnU-Net 原逻辑。
- 模型清单声明输入尺度单位时，预测输入会进行显式单位换算；尺度未经验证的输入会停止，不会被误当成可靠物理尺度。
- 新增整脑到脑区模型输入的严格清理工具：只保留主连通区域、记录物理裁剪和质量门禁，并为未通过案例生成仅供人工复核的 locator 候选。质量门禁通过只表示输入条件接近训练分布，不代表解剖学结果已经验证。

## 验证

- TaxaMask 统一验证套件：22 组、1,622 项通过；23 项因 Windows 符号链接权限或平台条件跳过。
- 内嵌 Ant-Code：4 项运行时测试通过；119 个 JavaScript 文件语法检查和 62 个 Dashboard 资源一致性检查通过。
- Node.js 生产依赖审计：193 个依赖，已知漏洞 0。
- Python 环境依赖一致性检查与 CVE 数据库审计通过；CUDA 专用 PyTorch wheel 不在 PyPI 审计数据库中，另按官方 PyTorch 来源管理。

## 升级注意

若外部后端配置原来依赖 `&&`、`|`、`>` 等 Shell 操作符，请先把命令写入 `.ps1`、`.cmd` 或 `.sh` 包装脚本，再在 TaxaMask 中配置该脚本及其参数。普通的单程序命令无需调整。
