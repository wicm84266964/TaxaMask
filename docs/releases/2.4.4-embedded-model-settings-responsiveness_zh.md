# TaxaMask v2.4.4：内嵌智能体模型配置响应修复

发布日期：2026-08-09

这是 v2.4 系列的补丁版本，主要修复内嵌智能体的模型配置弹窗在打开、点击和输入时严重卡顿的问题。该问题同时出现在 CPU/核显设备和 RTX 3090 设备上，根因不是显卡性能，而是 TaxaMask 中文适配脚本的文本写回逻辑。

## 问题与修复

- 模型配置的 5 个复选项标签都含有用于排版的前导空格。中文模式下，旧翻译逻辑会把带空格的原文再插回原文，使空格数量不断翻倍。
- 全页 `MutationObserver` 又会监听这次文字改动并在下一帧重新执行。很短的标签因此可在数十轮内增长到数千万字符，使 QtWebEngine 渲染进程占用数 GiB 内存，并在 JavaScript 主线程上触发重排和垃圾回收。
- 本版本将“未发生翻译”收敛为稳定的正规化结果，保留标签的排版空白，但不再无变化写回。品牌、权限、信任和动态状态文字也统一改为仅在内容真正变化时更新。

## 对研究工作流的影响

- 打开内嵌智能体的模型配置、切换输入框或点击弹窗空白区时，不再因文本节点膨胀而卡住数秒。
- 修复只作用于内嵌 Dashboard 的本地化和 DOM 更新边界，不修改已保存的模型、网关地址、API Key、会话历史、TIF 切片、标注或训练数据。
- CPU、核显和独显设备均受益。GPU 仍可用于网页合成，但不再需要替 JavaScript 字符串增长问题承担无法完成的“补救”。

## 同步包含的补充修复

`v2.4.3` 标签发布后，公开 `main` 已合并的内嵌 Ant-Code 状态补充修复也随本版本进入新标签：网关重试在最终失败前保持为主要活动状态，最终失败会收敛到同一条状态；`rg_files` 文件枚举也按目录范围参与委派判断。

## 验证范围

- 针对 5 个实际模型配置标签的中英文幂等性回归通过：中文重复执行不写回，英文最多写入一次后稳定。
- 真实 QtWebEngine 最小弹窗连续运行 6 秒：5 个标签文字长度不变，自触发文字 DOM 变更为 0，渲染进程内存约从 62.68 MB 到 62.76 MB。
- 内嵌智能体 GUI 用例 30 项、运行设备/API/TIF 上下文用例 17 项和内嵌 Ant-Code Node 用例 16 项在开发仓通过；119 个 JavaScript 文件语法和 62 个 Dashboard 资源一致性检查通过。
- 完整 GUI smoke 包含与本修复无关的重型图像与训练用例，本地 5 分钟门限内未全部完成；上线仍以正式公开仓 Windows、Ubuntu、macOS 和 Embedded Agent Center CI 全绿为硬门禁。

## 升级说明

修复发布后需完整退出并重启 TaxaMask，使旧的 QtWebEngine 渲染进程一并退出。仅关闭模型配置弹窗不会卸载旧脚本，也不会释放其已占用的内存。

## 发布后补充修复（最新 main 源码）

`v2.4.4` 版本号和标签保持不变。本次补充修复已进入最新 `main` 源码，不创建新的 Release：

- 内嵌浏览器运行时在显式注入全局配置、且项目配置指向同一协议和 URL 的网关时，会按模型 ID 合并两级模型档案；项目中的同名模型仍具有更高优先级。
- 修复新增全局模型后首次可用、切回项目默认模型后却从选择列表消失的问题。
- 不同网关端点的模型和凭据仍保持隔离，不会因合并逻辑互相串用。
- 内嵌 Ant-Code Node 回归用例更新为 17 项并全部通过。

### 修复面板凭据持久化

- 修复从 `启动AntCode修复面板` 保存 API Key 后，重新打开仍显示“未配置”的问题。根因是修复模式会跳过可能损坏的项目配置，但旧实现仍将凭据写入被跳过的 `.lab-agent/config.json`。
- 修复模式现在使用独立的用户配置文件：Windows 为 `%APPDATA%\TaxaMask\ant-code-recovery.config.json`；Linux 为 `$XDG_CONFIG_HOME/taxamask/ant-code-recovery.config.json`，未设置 `XDG_CONFIG_HOME` 时使用 `~/.config/taxamask/ant-code-recovery.config.json`。
- 恢复配置仅接受模型、网关和凭据字段，不能覆盖 TaxaMask 的 Hooks、权限或源码保护策略；正常内嵌模式继续使用项目配置，不受本次调整影响。
- 内嵌 Ant Code 版本更新为 `1.3.0-taxamask.2`。此前通过修复面板保存过但未被读取的 Key，需要在更新后的修复面板中重新保存一次。
- Windows、Ubuntu、macOS、Embedded Agent Center 和 Paper Distill Skill bundle 的公开仓 CI 均已通过。
