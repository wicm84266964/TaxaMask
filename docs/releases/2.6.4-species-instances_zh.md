# TaxaMask v2.6.4：物种与个体标注工作台及黑金主题

发布日期：2026-11-02

本补丁版本新增独立的“物种与个体标注”入口，支持在一张图片中为多个个体分别标记物种，并补齐 SAM 描边、人工复核、数据集导出、训练预测及智能体接口。统一工作台菜单与控件样式，首次启动默认采用黑金深色主题。

## 对研究工作流的直接变化

- 新工作台与材料处理中心、2D/STL、TIF/CT 并列。同种多只个体分别保存，不要求建立部位或性状树；支持画框、多边形、SAM 点选/框选、前景与背景点修正、顶点编辑、画笔和橡皮。
- 已确认标注发生几何或类别修改后重新进入待复核状态。检测/分割导出要求整图完整检查；智能体和模型建议始终先作为草稿。
- 提供 COCO、YOLO 与单体分类目录的导入导出及检测、实例分割、单体分类训练预测。外部后端可配置解释器、命令、任务能力和模型清单，运行记录接入既有训练账本。
- 材料中心只导入人工批准的图片与来源信息，不把文献中的物种建议自动变成训练标签。智能体通过实例专用接口检查、导出、训练、预测或提交草稿，不调用旧部位写入命令。
- 文件、工作流和通用设置菜单保持一致；下拉箭头统一为细线样式，修复数值框裁字。黑金主题的内嵌智能体直接使用 Ant Code Dashboard 原生配色，避免设置页混入蓝色。原浅色和深空霓虹选择继续保留；主题在通用设置保存后随下次启动恢复。

## 数据、模型与科学结论边界

新实例项目使用独立的 `project.instance.json` 和 `annotations.sqlite`，不会迁移或改写原 2D/STL、TIF/CT 项目、已有标注和 `manual_truth`。现有模型权重不被替换；实例训练生成独立权重及类别映射清单。

SAM 用于边界建议，不能证明物种身份。技术测试不等于分类学准确率或专家审核。COCO RLE 保留孔洞和断开区域；YOLO 无法表达的复杂掩膜会阻止导出，不静默丢失区域。单体分类须人工检查裁剪内是否仍含未标出的其他个体。

## 升级与产物位置

升级后完整重启软件，无需迁移已有项目数据。新建实例项目请选择空目录，图片副本位于 `media/`；编辑即时保存，数据库备份在 `backups/`。迁移项目应复制整个目录，数据库备份不能代替图片备份。

`exports/<export_id>/` 保存数据集、类别映射、划分与排除报告；`runs/<run_id>/` 保存训练日志、参数、模型清单、权重和账本；`agent_requests/` 保存草稿请求与回执。导出快照可能含本地来源信息，公开分享前需检查并脱敏。

## 验证、限制与待完成门禁

开发环境完成实例工作台 17 项、接口 11 项、主题控件 5 项、浏览器原生主题 1 项的针对性测试，并执行旧项目生命周期、主界面、SAM、训练真值和导出回归。测试套件之间可能覆盖相同行为，不合并宣称独立功能数量。

一张真实多个体照片的 5 项交互测试覆盖画框、重叠选择、轮廓修改、历史恢复、COCO 往返和真实 SAM 框/点/背景点推理；另有 1 项提示分组参数测试。图片不随源码公开。三任务各用合成图片在 CPU 上训练一轮、生成权重并重载预测；检测/分割该轮未产生目标预测，只能证明技术调用闭环。

跨平台 CI 加入实例、主题和浏览器样式测试；真实 SAM 权重测试在普通 CI 中明确跳过，不计作通过。发布候选仍须在正式仓复验，并以同一提交的 Windows、Ubuntu、macOS 及 Release 门禁为准。

尚未完成大批量真实标本与万图性能验收、完整专家轮廓审核、任意第三方模型验证及强制断电测试。部分导入和训练前准备仍会占用界面；类别导入按名称匹配，导出暂不自动脱敏。详细操作见 `docs/instance_workbench_zh.md`，验证范围见 `docs/validation/instance_workbench_validation_zh.md`。
