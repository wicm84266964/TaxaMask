# TaxaMask v2.6.2：内嵌智能体模型来源与本机 Node 准备

发布日期：2026-10-19

`v2.6.2` 是一次小版本。Agent Center 的内嵌运行时从 `2.0.5-taxamask.1` 同步到 `2.0.24-taxamask.1`。研究者可以用路线名添加模型来源，长对话会保留工具证据，并在对话区用灯丝跳回已发送提示。新电脑安装时会把合格的 Node.js 放进当前 Python 环境，避免只看到旧的 22.14 就改走 WSL。项目格式、已有标注和 `manual_truth` 不变。本说明处于公开发布候选阶段，不表示跨平台 CI、tag 或 GitHub Release 已经完成。

## 对研究工作流的直接变化

- Agent Center：设置页按路线名添加来源，一次读入该路线的模型，聊天栏按路线切换。同一地址的不同密钥用不同路线名，不再手选“同一网关的生效 Key”，也不再发小图探测视觉或提供“检测档位”。
- 很早保存的单模型渠道刷新时写回原来的项目或全局范围，不会复制成一条全局同名来源，也不会让设置页整页失败。
- 输入栏可以附上 PDF 或常见文档给模型阅读。这只是对话里的临时阅读，不是文献筛选库，也不会打开独立版左右栏。
- 长对话会在上下文快满时摘要旧工具结果，需要核对时仍可取回摘要前的原文。很长的会话按交接摘要加短尾巴继续，减少整轮发不出去。
- 对话区左缘有灯丝，可跳回已发送提示。浅色用 `#08789F`，深色用 `#8FAED4`，不使用独立版暗金。
- 子智能体选模型使用自绘列表。悬停时有底色提示，鼠标离开后底色消失。同一模型若同时有带前缀的名字和纯模型名，只保留带前缀的那条。
- 定时任务、左右栏会话搜索和右侧产物栏不进入内嵌界面。
- 新电脑在已激活的 Python 环境中运行 `python scripts/ensure_agent_node.py --npm-ci`，会把 Node.js 22.22.2 放进该环境。Windows 上是 `python.exe` 旁边的 `node.exe`。`启动TaxaMask.bat` 和 `启动TaxaMask.sh` 每次启动也会做同样准备。没有 WSL 的机器继续用本机 Node。

## 数据、模型与科学结论边界

- 不迁移已有 PDF、2D/STL、TIF/CT 项目，不改写标注、`manual_truth`、模型权重或训练账本。
- 聊天里附上的 PDF 不是筛选结果，也不能变成训练真值。
- 没写保留天数的新会话默认永久保留。已经写成具体天数的项目配置不改。高敏感配置仍是 0 天。
- 本版本改善的是智能体配置、长对话证据和启动准备，不证明文献判断、分割结果或分类学结论。

## 升级与产物位置

- 更新后请完整退出并重启 TaxaMask，以加载新的内嵌运行时和本机 Node。
- 无需迁移已有项目数据。
- 升级后打开 Agent Center 设置页，按路线名确认模型来源和当前生效凭据。
- 本版本不包含 API Key、本机设置、项目数据库、模型权重、PDF/TIF 数据或运行产物。
