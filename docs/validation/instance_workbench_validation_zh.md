# 物种与个体工作台：实现与验证记录

日期：2026-11-02。以下为开发工作区的验证记录；发布候选另在正式仓复验，线上状态以对应 Release 和 CI 为准。

## 实际实现

新增主界面独立入口及项目类型 `species_instances_2d`。SQLite 连接、文件锁、原子写入、画布视图、SAMWorker、外部命令解析和训练账本沿用现有基础设施；实例业务、数据集适配和独立页面为新增代码。当前加载器会拒绝将新项目作为旧部位项目读取，未声称验证过历史二进制程序。

提供框、多边形、SAM 点/框提示、背景点、顶点与画笔修补、多个体管理、批量确认、撤销恢复、材料和 COCO/YOLO/分类导入导出、三任务训练预测、外部后端设置及智能体草稿队列。训练生成带类别身份和权重指纹的模型清单，使用既有 TrainingRunRecorder 留存输入与产物。

与设计建议的具体差异：掩膜直接以完整 RLE 保存于实例记录，不建立 masks 文件树；图像始终复制到 media，不提供外部原图引用；外部协议最终名称以 docs/contracts 下文档为准。分类、检测、分割均在本次实现，不拆成后续阶段。

## 真实模型技术检查

`tests/instance_training_smoke.py` 在 12 张可复现合成图上，使用本地 Ultralytics 8.4.60，CPU、64 像素输入、每任务 1 轮：detect、segment、classify 均生成权重、记录成功并重载预测。检测/分割预测数均为 0，分类返回 1 条建议；只验证模型调用和输出闭环，不能宣称已经学会识别。

现有 sam_b 权重在 CPU 上实际推理返回一个 64×64 掩膜。Qt 工作台 1200×700 截图已查看，中文文字可读；另用自动化验证了界面编辑、历史往返及队列刷新。这不替代人工鼠标操作验收。

外部后端使用可复现的小适配脚本验证真实子进程与含空格路径、同类两个预测对象、COCO 训练输入和账本，不代表任何特定第三方模型已经验证。

## 尚未完成的验收

### 主题与真实图片补充验证（2026-11-02）

共用主题新增 `classic_dark`，最终采用 Ant Code Dashboard 黑金配色，并作为未配置主题时的默认值，保留原 `dark` 深空霓虹及 `light`。通用设置选择和 TIF 面板跟随主题，保存后记住选择。菜单按钮（含旧 2D 工作台 QToolButton）、组合框及数值框统一使用 SVG 细线箭头；数值框内部编辑器取消重复边距。

新增 `test_shared_theme_controls.py`：最终 5 项通过，覆盖三主题选择/恢复、首次默认与配置保存、TIF 配色、SVG 可加载、菜单按钮随主题刷新、百分比及正负小数显示宽度和键盘编辑。另有 `test_agent_native_theme.py` 1 项实际浏览器样式测试通过，验证内嵌智能体沿用原生黑金配色和主题往返切换。另通过 TIF 样式 1 项、主界面 7 项、原 SAMWorker 9 项回归；原实例工作台 17 项和接口 11 项再次通过。

用户提供一张 474×293 多只蚂蚁的真实照片，复制到临时独立项目进行测试；原图片和用户项目未改写。`test_instance_canvas_interactions.py` 在该图片上完成 5 项实际交互测试：鼠标拖框、重叠循环选择、确认/删除/撤销/重做、独立数据库重开读取、多边形、顶点拖动/增加/删除、画笔/橡皮、提示取消、COCO 完整掩膜往返，以及真实 sam_b 的框选/点选/背景点候选与采用后草稿、确认。另有 1 项模型调用参数测试专门核对多点属于同一个体。真实 SAM 检查使用 CPU，完整 5 项运行约 47 秒，无跳过。

真实图片检查发现并修正了实例 SAM 的多点形状：前景和背景点现作为同一对象的提示组传入，避免被解释为不同对象。未改动旧部位提示接口。测试环境还出现过首次在 Qt 后台线程导入原生模型库的 Windows 异常；测试初始化已与桌面启动顺序对齐（先加载模型库），等待循环释放 Python 执行锁，后续两轮完整运行通过。

这仍不等于“全部新增功能已用真实数据验收”：照片仅一张，分类使用测试类别名；轮廓并未由分类学专家逐像素验收。三任务训练仍是合成数据技术检查，任意外部模型、批量真实标本、跨平台与长时间稳定性没有因此得到验证。常规测试默认生成图片；设置 `INSTANCE_TEST_IMAGE` 可指定真实图片，`INSTANCE_TEST_SAM` 可启用本地权重推理，未设置权重时该项明确跳过。私人图片不纳入源码。

真实蚂蚁标本的人工全流程复核、万图/百个体性能基线、完整桌面应用实机交互、磁盘满和强制断电故障注入，以及 macOS/Linux 平台运行尚未完成。导入映射当前按类别名称匹配，不提供逐项映射预览；分享导出尚需手动脱敏；大批量导入和训练前导出不是全程后台。完整验收时应继续核对原设计第 10 节，不能把已通过的针对性套件当作整份验收清单全部通过。

临时合成数据、训练权重、日志和截图只用于本次验证，保存在被忽略的 `.tmp_validation/` 中；本次清理操作被执行策略拒绝，故暂留本地、不纳入源码。可用仓库内测试重新生成。研究项目与旧工作台标注无需迁移。
