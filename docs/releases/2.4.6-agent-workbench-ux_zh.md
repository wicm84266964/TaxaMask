# TaxaMask v2.4.6：Agent 与工作台交互体验优化

发布日期：2026-08-17

这是 v2.4 系列的小版本更新。它不改动项目数据格式、模型权重或训练/标注算法，只优化启动中心、内嵌 Agent 面板、2D/STL 标注工作台和 TIF 体数据工作台的交互与布局，并补齐 WSL/内嵌运行环境下与界面体验直接相关的兼容处理。

## 启动中心与内嵌 Agent

- “启动 Ant-Code / 停止 Ant-Code”按钮按运行状态联动：启动中、运行中禁止重复启动；未运行时停止按钮不可用。
- 浏览器模式下停止 Dashboard 后再次启动，会重新自动打开浏览器，不再因上一次打开记录而跳过。
- fallback 页新增“在浏览器中打开”“重新加载 Dashboard”“再次复制 Agent 上下文”三个恢复入口。
- Dashboard URL 可选中复制，fallback 内容可滚动，相关提示补齐中文翻译。
- 内嵌模式下加载完成前保持 fallback 提示页，加载完成后才切换到 Dashboard，减少黑色首帧闪烁。

## 2D/STL 标注工作台

- 右侧检查器改为“当前图片 / 自动标注 / 运行与日志”三个标签页，运行状态和日志首屏可见。
- 顶部低频操作收入“更多操作”菜单，避免窄窗口下工具栏溢出。
- “当前图片物种”上移到结构标签树之前；“结构标签”树高度可在 140–300px 间伸缩。
- Ctrl+S 恢复为标准保存快捷键；“验证当前图片”改为 Ctrl+Enter 并加入工作流菜单。
- 移除隐藏且无入口的“打开子部位专家会话”死按钮。
- 为“手动绘制 / 魔棒 (SAM)”补充悬停提示，并统一 SAM、VLM、TIF 等中文文案。

## TIF 体数据工作台

- 右侧固定区只保留“操作状态”，任务标签页获得更多可用高度。
- 首个标签页命名为“导入与预览”，“数据导入”区块移动到该页顶部。
- “网格导出”移动到“结果对比”标签页顶部，按钮行为不变。
- 顶部栏增加精简运行状态显示，切换标签页时仍能看到后端任务进度。

## WSL 与内嵌运行环境

- 当用户配置目录不可写时，自动回退到仓库 `TaxaMask_outputs` 下的配置目录，避免切换语言或写入配置时报 `PermissionError`。
- WSL 没有中文字体时，自动使用 Windows 侧微软雅黑/宋体并配置仓库内 fontconfig 缓存，修复中文显示异常。
- TIF 后端 Python 自动探测跳过无权限目录，修复进入 TIF 工作台时因扫描受限目录而失败的问题。

## 数据边界

本版本不包含私人研究数据、项目数据库、TIF/CT 体数据、标注真值、模型权重或 API 配置。

## 升级说明

更新后请完整退出并重启 TaxaMask。Windows 用户双击 `启动TaxaMask.bat`；WSL/Linux 用户使用 `启动TaxaMask.sh`。旧项目无需迁移。

## 发布后补充修复（最新 main 源码）

`v2.4.6` 标签和版本号保持不变。本次补充修复进入最新 `main` 源码，不创建新的 Release：

- Dashboard 健康检查超时但进程仍存活时，“停止 Ant-Code”保持可用，用户可以直接结束无响应的服务。
- 此时再次点击“启动 Ant-Code”会重新执行健康检查；只有 Dashboard 接口真正恢复后，界面才进入“运行中”，不再仅凭进程存在就误报已就绪。
- 新增进程存活但服务不健康的状态联动回归测试，不修改会话、模型配置、API Key 或研究项目数据。
