# TaxaMask v2.4.7：TIF 滑条与 Windows 启动修复

发布日期：2026-08-18

这是 v2.4 系列的小型修复版本。它改善大型 TIF/CT 体数据的切片浏览，并固定 Windows 启动脚本的行尾格式；不修改源 TIF、标注、训练数据、模型权重、API Key 或项目数据库。

## 大型 TIF 切片浏览

- 修复拖动底部切片滑条时，每经过一个页码都立即排队读取 TIF 切片，导致机械盘、CPU 或大体数据场景下反复显示“正在读取”并滞后追赶的问题。
- 快速拖动期间页码继续即时跟随手柄，但切片读取会合并到最新位置；停顿约 90 毫秒时可以预览当前页，松手后立即读取最终页。
- 如果停顿预览已经读取了松手位置，不会重复读取同一张切片。旧异步任务仍由请求令牌隔离，不能用过期画面覆盖研究者最终选择的页码。
- 鼠标滚轮、方向键翻页、Z/Y/X 轴切换和现有标签叠加行为保持不变。

## Windows 启动脚本

- 根仓库明确规定 `.bat` 和 `.cmd` 使用 CRLF，避免本地行尾统一工具或 Git 配置把 Windows 启动入口写回 LF。
- 内嵌 `vendor/ant-code` 原有的全文本 LF 规则增加 Windows 脚本例外，确保内层规则不会覆盖根规则。
- 启动脚本的命令内容没有变化；本次只固定检出格式，降低 `cmd.exe` 在不同 Windows 环境下解析失败的风险。

## 同步包含的补充修复

- 收纳 `v2.4.6` 标签之后已进入 `main` 的 Agent 恢复修复：Dashboard 健康检查超时但进程仍存活时，停止按钮保持可用；重新启动会再次检查服务，只有接口真实恢复后才显示“运行中”。

## 验证范围

- 开发仓和正式发布候选仓分别执行完整 TIF 工作台测试：各 240 项全部通过。
- 定向 GUI 回归覆盖快速拖动、停顿预览、松手最终页、异步请求合并、滚轮/方向键翻页及 Z/Y/X 轴切换。
- Python 语法编译、`git diff --check`、开发仓到正式仓逐文件哈希比对和发布敏感文件扫描均通过。
- Windows 行尾属性检查确认两个 `.bat` 启动入口及内嵌 Ant-Code `.cmd` 均为 `eol=crlf`。

## 升级说明

更新后请完整退出并重启 TaxaMask。Windows 用户继续双击 `启动TaxaMask.bat`；已有项目和 TIF 工作卷无需迁移。
